# Bundled fonts

`DejaVuSans-Subset.ttf` and `DejaVuSans-Bold-Subset.ttf` are subsets of DejaVu Sans / DejaVu Sans Bold
(Latin, Latin-1 Supplement, Latin Extended-A, common punctuation, `€`, `№`, `™`, `−`) — enough for Czech,
Slovak, Polish, German and English documents. They were produced with `fontTools.subset` (no hinting, no
layout tables) to keep generated PDFs small (~23 kB per font).

DejaVu fonts are free to redistribute and embed; see `LICENSE_DEJAVU`.
