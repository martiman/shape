# Shape Architecture

## Source of truth

- `packages/shape` contains the Shape framework library.
- `packages/shaperuntime` contains the underlying runtime engine, documented as ShapeRuntime.
- `apps/bookshop` contains the Shape example application.

## Relationship to ShapeRuntime

Shape is a layer on top of ShapeRuntime, not a replacement. It uses the runtime's:
- `MaskRegistry` for query execution
- `ValidatorRegistry` for mutation validation
- `BatchExecutor` for query and mutation processing
- `CommandExecutor` for business logic commands
- `Database` for PDO access
- `JwtGuard` / `LoginService` for authentication

Shape adds:
- Entity attribute system (PHP 8 native attributes, including descriptions, enum values, unique constraints, and writable modes)
- Metadata reader (reflection-based, zero dependencies)
- Mask generator (entity → query masks)
- Validator generator (entity → field validators)
- Manifest generator (entity → API discovery endpoint)
- Config builder (merges auto-generated + manual config)

## Package structure

```
packages/shape/src/Shape/
├── Attribute/              ← PHP 8 attribute classes
│   ├── Entity.php          #[Entity('table', description, writableMode)]
│   ├── Column.php          #[Column(type, length, values, description, ...)]
│   ├── Id.php              #[Id]
│   ├── AutoIncrement.php   #[AutoIncrement]
│   ├── FK.php              #[FK(entity, column)]
│   ├── Validate.php        #[Validate('rule', values)]
│   ├── Unique.php          #[Unique(['a', 'b'])]
│   └── Access.php          #[Access(roles, read, write)]
├── Metadata/               ← Reflection-based metadata extraction
│   ├── FieldMeta.php       Field metadata value object
│   ├── EntityMeta.php      Entity metadata value object
│   └── EntityReader.php    Scans directory → EntityMeta[]
├── Generator/              ← Config generators
│   ├── MaskGenerator.php       EntityMeta → ShapeRuntime masks
│   ├── ValidatorGenerator.php  EntityMeta → ShapeRuntime validators
│   └── ManifestGenerator.php   EntityMeta → JSON manifest
├── ShapeApp.php            ← Config builder (entities + manual → merged config)
└── ShapeRouter.php         ← HTTP handler (extends ShapeRuntime with manifest op)
```

## Application structure

```
apps/myapp/
├── entities/           ← One PHP class per entity
│   ├── Order.php
│   ├── Item.php
│   └── Stock.php
├── config/
│   ├── app.php         ← Commands + manual overrides
│   ├── env.php         ← DB/auth settings (production)
│   └── env.local.php   ← DB/auth settings (local dev, takes priority)
├── database/
│   ├── schema.sql      ← Database schema
│   └── seed.sql        ← Seed data
├── public/
│   └── api.php       ← Entry point
└── bootstrap.php       ← Autoloader
```

## Request flow

```
HTTP POST → ShapeRouter::run()
                │
                ├─ GET → health check JSON (no DB)
                ├─ manifest → ManifestGenerator (no DB)
                │
                └─ query/mutation/command/auth
                       │
                       ▼
                   Database created (lazy)
                       │
                       ▼
                   ShapeRuntime execution engine
                   (MaskRegistry, ValidatorRegistry, BatchExecutor, etc.)
```

Key design: Database connection is lazy. Health check and manifest work without a database connection. This makes local development and testing simpler.

## Config merge strategy

```
ShapeApp::fromEntities()

  1. Load app.php          → manual masks, validators, commands
  2. Load env.local.php    → db, auth (if exists, overrides env.php)
     or env.php
  3. Scan entities/        → EntityMeta[]
  4. Generate masks        → auto masks
  5. Generate validators   → auto validators
  6. Merge: auto + manual  → manual always wins for same key

  Result: complete config for ShapeRouter
```

## What the AI agent writes vs. what the framework generates

| Written by agent | Generated by Shape |
|------------------|--------------------|
| Entity class (20-30 lines) | Query masks (list, get, getMany, byFK) |
| Commands (business logic) | Field validators (from #[Validate]) |
| Custom hooks (optional) | Writable masks (from #[Entity]) |
| | API manifest |
| | Role-based access (from #[Access]) |

## Zero-dependency principle

Shape uses only:
- PHP 8.2 native `#[Attribute]` and `Attribute` target constants
- PHP `ReflectionClass`, `ReflectionProperty`, `ReflectionNamedType`
- ShapeRuntime's existing classes

No Composer packages, no vendor directory, no autoloader beyond PSR-4.
